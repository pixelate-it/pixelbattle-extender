## How to use

> [!IMPORTANT]
> Uses new format!

For extend canvas from old:

1. Dump `pixelbattle/pixels` collection from mongodb, with selected to JSON
2. In program select canvas file.
3. Select the tab with the functionality you are interested in.
4. Press "Start", and enjoy functionality!

For creating new canvas:

**Select the Empty tab, and write the desired size, with color. Done!**
